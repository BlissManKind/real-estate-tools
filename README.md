# Real Estate Tools

Two property questionnaire forms built for a real estate client. Each form collects detailed property information and generates a downloadable PDF.

## Live demos

- [Residential questionnaire](https://thriving-unicorn-29f960.netlify.app/) — apartment & residential property
- [Commercial questionnaire](https://fantastic-florentine-641156.netlify.app/) — office & commercial space

## Features

- Detailed property data collection
- PDF export with one click (html2pdf.js)
- Responsive layout — works on mobile and desktop
- Clean two-column grid layout
